# حساب التصفية

## قبل البدء
1. جهّز [لوائح الفروع](03-لوائح-الفروع.md).
2. جهّز [أنواع التصفية](04-أنواع-التصفية.md).
3. تأكد من [عقد الموظف](05-عقد-الموظف.md).
4. عند الحاجة: [الأرصدة الافتتاحية](06-الأرصدة-الافتتاحية.md) · [السلف](07-السلف.md) · [بدلات واستقطاعات أخرى](08-بدلات-واستقطاعات-أخرى.md) · [رسوم إدارية](09-رسوم-إدارية.md) · [الحضور](10-الحضور.md).

## خطوات الحساب
1. افتح **حساب التصفية** (`EOService-calc`).
2. جديد.
3. اختر **الموظف** (بحث ← اختر).
4. راقب ملصق الجاهزية بجوار الموظف.
5. لو ظهر **بيانات ناقصة** أو **يحتاج مراجعة** ← [تهيئة الراتب](02-تهيئة-الراتب.md).
6. أدخل **تاريخ البدء** (تاريخ التصفية).
7. اختر **نوع التصفية**.
8. اضغط **حساب التصفية**.
9. راجع أقسام: **الاجازات** · **المستحقات** · **بدلات واستقطاعات أخرى** · **رسوم ادارية** · **العهد المادية**.
10. لو بدل الإجازة / المكافأة = 0 ← [عقد الموظف](05-عقد-الموظف.md) و[الأرصدة الافتتاحية](06-الأرصدة-الافتتاحية.md).
11. لو ظهرت قيمة السلف ← [السلف](07-السلف.md).
12. أضف أو عدّل سطور **بدلات واستقطاعات أخرى** عند الحاجة ← [بدلات واستقطاعات أخرى](08-بدلات-واستقطاعات-أخرى.md).
13. اختر سطور **رسوم ادارية** عند الحاجة ← [رسوم إدارية](09-رسوم-إدارية.md).
14. احفظ.

## المراجعة والصرف
1. افتح **مراجعة وصرف التصفيات** (`EOService-review`).
2. اختر الحركة.
3. **حساب الشهر** (إنهاء خدمة / إجازة بدون مرتب) — يُتخطى في **تصفية مع البقاء**.
4. **تأكيد المراجعة**.
5. **صرف**.
