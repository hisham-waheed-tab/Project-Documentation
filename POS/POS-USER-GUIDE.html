👋قبل أن تبدأ

لمن هذا الدليل؟ لمدير المشروع / المختبِر.

كل خطوة: الشاشة ← ماذا تفعل ← ماذا يظهر.

🌐1. إعداد الويب

  1. نظام نقطة البيع ← الخزن النقدية ← إضافة خزنة (الكود، الاسم، الفرع) ← حفظ ← تظهر في القائمة.
  2. نقاط البيع ← إضافة (الكود، الاسم، الفرع، الخزنة الافتراضية، المخزن الافتراضي) ← حفظ ← تظهر في القائمة.
  3. نقاط البيع ← فعّل «السماح بالبيع أوفلاين» لو ستختبر بدون إنترنت.
  4. طرق الدفع ← راجع النقدي والبطاقة (الاسم، الحد الأقصى، مسموح أوفلاين، تقسيم الدفع) ← حفظ.
  5. فروع المستخدمين ← اختر الكاشير ← علّم الفرع ← عيّنه فرعًا افتراضيًا ← حفظ.
  6. صلاحيات المستخدم ← اختر الكاشير ← صفحة «كاشير نقطة البيع» ← علّم دخول + إضافة ← حفظ.
  7. صلاحيات المستخدم ← اختر المشرف ← صفحة «مشرف نقطة البيع» ← علّم إضافة ← حفظ.
  8. فروع المستخدمين ← اربط المشرف بنفس الفرع ← حفظ.
  9. رموز PIN للمشرفين ← أمام المشرف اضغط «تعيين رمز» ← اكتب رمزًا من 6–8 أرقام (غير مكرر وغير متتالي) ← حفظ.
  10. رموز PIN للمشرفين ← اختر الفرع ← يظهر المشرف «نعم» في عمود «يظهر كمشرف؟».
  11. لو ظهر «لا» ← اقرأ السبب المكتوب بجانبها ← أكمل الشرط الناقص ← حدّث الشاشة.

⚠️ الخزنة ونقطة البيع لازم يكونا من نفس الفرع.

💡 مدير الشركة يكفيه رمز PIN مفعّل فقط ليكون مشرفًا.

🖥️2. برنامج الكاشير

2.1 التثبيت والدخول

  1. اضغط مرتين على ملف التثبيت ← يظهر اختصار TABMS POS على سطح المكتب.
  2. لو ظهرت رسالة ويندوز الزرقاء ← More info ← Run anyway.
  3. افتح البرنامج ← دخول ← سجّل في المتصفح ← اضغط Open Electron ← يرجع للبرنامج.
  4. نافذة «رمز الدخول بدون اتصال» ← اكتب رمزًا شخصيًا 6–8 أرقام ← حفظ الرمز.

2.2 فتح الوردية

  1. فتح وردية جديدة ← اختر الطرفية ← اكتب الرصيد الافتتاحي.
  2. اضغط فتح الوردية والبدء ← تظهر شاشة البيع.

2.3 البيع والدفع

  1. شاشة البيع ← اكتب باركود أو اسم أو كود الصنف ← اختره ← يُضاف للسلة.
  2. عدّل الكمية أو السعر أو الخصم من سطر الصنف (لو مسموح).
  3. (اختياري) اختر العميل ← بحث بالاسم أو الهاتف، أو «متابعة البيع بدون عميل».
  4. اضغط إتمام الدفع ← اختر نقدي / بطاقة / مختلط.
  5. نقدي ← اكتب المبلغ أو «المبلغ بالضبط» ← يظهر الباقي.
  6. تأكيد ← تظهر «تم إتمام البيع بنجاح» ← بيع جديد.

2.4 تعليق الفاتورة واسترجاعها

  1. شاشة البيع ← تعليق ← (ملاحظة اختيارية) ← تفرغ السلة.
  2. الفواتير المعلقة ← استرجاع ← ترجع الأصناف للسلة.

2.5 موافقة المشرف

  1. عند خصم كبير أو عملية تحتاج موافقة ← تظهر نافذة الموافقة.
  2. اختر المشرف ← يكتب رمزه ← اعتماد ← تكمل العملية.

2.6 المرتجع والاستبدال

  1. عمليات ← المرتجعات ← اختر مرتجع أو استبدال.
  2. ابحث برقم الفاتورة أو هاتف العميل ← افتح الفاتورة.
  3. حدد الأصناف والكمية ← اختر السبب.
  4. (لو طُلبت) موافقة المشرف ← اختر طريقة رد المبلغ ← تأكيد ← يتم المرتجع.
  5. في الاستبدال ← اختر الصنف البديل ← ادفع أو استرد الفرق.

2.7 الحركات النقدية

  1. عمليات ← أدوات الكاشير ← إضافة نقدية / سحب نقدي / توريد للآمن.
  2. اكتب المبلغ ← اختر السبب ← حفظ (أو «اعتماد مشرف وحفظ») ← تظهر في سجل اليوم.

2.8 إغلاق الوردية

  1. عمليات ← إغلاق الوردية ← راجع ملخص الوردية ← التالي.
  2. جرد النقدية ← اكتب المبلغ الفعلي في الدرج.
  3. لو فيه زيادة أو عجز ← اختر السبب (وموافقة مشرف لو الفرق كبير).
  4. تأكيد ← تظهر «تم إغلاق الوردية بنجاح» ← تسجيل الخروج.

2.9 العمل بدون إنترنت

  1. افصل الإنترنت (أو الأجهزة والاتصال ← تشغيل وضع عدم الاتصال يدويًا) ← المؤشر يصبح «غير متصل».
  2. بِع كالمعتاد ← العملية تُحفظ على الجهاز.
  3. للدخول بدون إنترنت ← شاشة الدخول ← «دخول بدون اتصال» ← اكتب رمز الدخول بدون اتصال.
  4. أرجع الإنترنت ← سجّل الدخول متصلًا بنفس المستخدم.
  5. الأجهزة والاتصال ← مزامنة الآن ← عداد «بانتظار المزامنة» يصبح صفرًا.

2.10 رسائل شائعة

الرسالة ماذا تفعل
لم يتم تحديد فرع افتراضي. فروع المستخدمين ← عيّن فرعًا افتراضيًا
لا توجد نقاط بيع مسجّلة لهذا الفرع. نقاط البيع ← أضف نقطة بيع على الفرع
الخزنة الافتراضية لنقطة البيع تابعة لفرع آخر… اجعل الخزنة ونقطة البيع من نفس الفرع
لا يوجد مشرفون معرّفون لهذا الفرع برمز PIN رموز PIN للمشرفين ← أكمل الشرط الناقص
حسابك ليس لديه صلاحية تنفيذ هذه العملية (…) أضف الصلاحية المكتوبة ← سجّل الدخول من جديد
عمليات مسجّلة باسم مستخدم آخر موقوفة… ادخل بنفس المستخدم صاحب العمليات

2.11 الإبلاغ عن مشكلة

  1. صوّر الشاشة وفيها رسالة الخطأ.
  2. اكتب الوقت، واسم المستخدم، ورقم الفاتورة (إن وُجد).
  3. أرسل ملفات السجل من %APPDATA%\tabms-pos-desktop (الملف pos-auth.log وملف اليوم داخل مجلد logs).

🛡️3. السياسات

  1. سياسات نقطة البيع ← اختر المستوى والجهة (مثلًا نقطة البيع).
  2. اضغط تخصيص على السياسة ← غيّر القيمة ← حفظ.
  3. معاينة السياسات الفعّالة ← اختر نقطة البيع والمستخدم ← تأكد من القيمة.
  4. في البرنامج ← أدوات الكاشير ← تحديث السياسات ← يطبّق التغيير فورًا.

📊4. مراقبة العمليات

  1. مراقبة عمليات نقاط البيع ← اختر الفترة «اليوم» والفرع.
  2. سجل العمليات ← تأكد أن كل فواتيرك ومرتجعاتك وورديتك ظاهرة بنفس المبالغ.
  3. فلتر تحتاج انتباه ومشاكل مزامنة ← المفروض لا يوجد شيء غير مفهوم.

🚧5. ما ليس حقيقيًا بعد

  • الدفع بالبطاقة محاكاة (النتيجة عشوائية).
  • الطباعة محاكاة (لا يخرج ورق).
  • اختبار الطابعة وجهاز الدفع والماسح محاكاة.
  • رصيد المخزون ونقاط الولاء غير متاحة.
  • اختصارات لوحة المفاتيح (F1–F10) لا تعمل.
  • آخر العمليات وإعادة طباعة آخر إيصال بيانات تجريبية.
  • المقاسات، الرقم التسلسلي، إيصال هدية، إرسال الإيصال، صنف مفتوح، وضع التدريب: غير مكتملة.
  • الفواتير المعلقة على نفس الجهاز فقط.
