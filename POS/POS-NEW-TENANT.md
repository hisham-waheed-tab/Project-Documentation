# تشغيل عميل جديد من الصفر حتى البيع (لموظف المشاريع والدعم)

آخر تحديث: 2026-10-13

## أ. التينانت والمستخدمين (Administration)

1. إنشاء التينانت ومديره (Host).
2. دخول مدير التينانت.
3. الفروع.
4. التأكد من وجود العملة في «العملات».
5. المستخدمين: كاشير، مشرف، مدير مخزن.
6. ربط كل مستخدم بفرعه، وتحديد **الفرع الافتراضي**.

## ب. المخزون (Inventory)

7. الوحدات.
8. المجموعات والمجموعات الفرعية.
9. المخازن: مخزن لكل فرع فيه نقطة بيع.
10. أنواع الحركات:
    - «رصيد افتتاحي»: حركة، وارد، أخرى.
    - «مبيعات نقطة البيع»: استخدام النظام = مبيعات نقطة البيع.
    - «مرتجع مبيعات نقطة البيع»: استخدام النظام = مرتجع مبيعات نقطة البيع.
11. مركز الأصناف ← الأصناف: الوحدة الأساسية، وحدات البيع الأخرى ومعاملها.
12. الأصناف ذات المقاسات/الألوان: الأبعاد ← توليد الـ SKUs.
13. الباركود: لكل SKU ووحدة.
14. مركز الأصناف ← «قوائم الأسعار»: قائمة بعملتها ← اختيار الفروع التي تستخدمها افتراضيًا.
15. الأسعار: لكل صنف (أو SKU) ووحدة في القائمة.
16. رصيد أول المدة: حركة «رصيد افتتاحي» على مخزن نقطة البيع.

## ج. نقطة البيع (POS)

17. `POST /api/v1/PosTenantSetup/InitializeDefaults` بـ `{ "dryRun": true }` ← مراجعة ← `{ "dryRun": false }`.
18. بعد أي تحديث للنظام: `POST /api/v1/PosTenantSetup/SyncMissing` بنفس الـ body.
19. «الخزن النقدية» لكل فرع.
20. «نقاط البيع» لكل جهاز:
    - الفرع.
    - الخزنة الافتراضية (نفس الفرع).
    - **المخزن الافتراضي** (إلزامي عمليًا).
    - قائمة الأسعار (فارغة = قائمة الفرع).
21. «إعدادات الأصناف» (اختياري): إخفاء صنف، تسليم مؤجل.
22. السياسات. ([الدليل](https://hisham-waheed-tab.github.io/Project-Documentation/POS/POS-POLICIES-GUIDE.html))

## د. الصلاحيات

23. الكاشير: «كاشير نقطة البيع» (وصول + إدراج).
24. المشرف: «مشرف نقطة البيع» (إدراج) + رمز من «رموز PIN للمشرفين».
25. من يرفع عمليات غيره من الجهاز: «مزامنة جهاز نقطة البيع» (إدراج).
26. حفظ الصلاحيات ← مزامنة صلاحيات ABP.

## هـ. الجهاز

27. تثبيت الديسكتوب. ([التثبيت](POS-DESKTOP-PUBLISH.md))
28. دخول الكاشير (متصل) ← تعيين رمز الدخول بدون اتصال.
29. فتح الوردية: **نقطة البيع الخاصة بهذا الجهاز** + الرصيد الافتتاحي.
30. بيع تجريبي بالباركود.
31. إقفال الوردية.

## و. التحقق بعد أول وردية

32. حركات المخزون: ظهور «مبيعات نقطة البيع» ونقص رصيد المخزن.
33. لو لم تظهر: `GET /api/v1/PosInventoryPostingBatch/GetAllData` على POS API ← `status` و`failurereason`.
34. بعد الإصلاح: `POST /api/v1/PosInventoryPostingBatch/Retry?id=`.

## مشاكل شائعة

| العَرَض | المراجعة |
|---|---|
| كل الأصناف «بدون سعر» | قائمة الجهاز أو قائمة الفرع (خطوة 14، 20) |
| صنف واحد «بدون سعر» | سعره في القائمة وتاريخ السريان (خطوة 15) |
| الرصيد لا يظهر | مخزن نقطة البيع (خطوة 20) |
| الباركود لا يُقرأ | باركود الـ SKU والوحدة (خطوة 13) |
| الترحيل فاشل: نوع حركة | خطوة 10 |
| الترحيل فاشل: صلاحية | خطوة 23 و26 |
| لا تظهر نقاط بيع عند فتح الوردية | الفرع الافتراضي للمستخدم (خطوة 6) |
