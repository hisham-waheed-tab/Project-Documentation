# تشغيل لوحات المعلومات لعميل ديسكتوب (لموظف الدعم)

آخر تحديث: 2026-10-29

## أ. قاعدة بيانات العميل (SQL Server)

1. تشغيل السكريبت [desktop-dashboard-views.sql](desktop-dashboard-views.sql) على قاعدة بيانات العميل (ينشئ/يحدّث الـ Views التي تبدأ بـ `web_`؛ آمن لإعادة التشغيل).
2. التأكد من ظهور 26 View تبدأ بـ `web_`.
3. إنشاء مستخدم SQL للقراءة فقط (`db_datareader`) على قاعدة العميل.
4. التأكد أن السيرفر متاح من الإنترنت (IP عام + بورت SQL مفتوح لسيرفر تاب).

## ب. التينانت (Administration – Host)

5. تاب أدمن ← «تخصيص البرامج للمستأجرين» ← التينانت ← إضافة نظام **«لوحات المعلومات»** ← حفظ (مدير التينانت يأخذ الصلاحيات تلقائيًا).
6. دخول مدير التينانت ← التأكد من ظهور نظام «لوحات المعلومات».

## ج. مصدر البيانات

7. لوحات المعلومات ← الإعدادات ← **مصادر البيانات** ← إنشاء.
8. الكود + الاسم عربي/إنجليزي + نوع القاعدة: SQL Server.
9. نص الاتصال:
    `Server=IP,Port;Database=اسم_القاعدة;User Id=المستخدم;Password=كلمة_المرور;TrustServerCertificate=True;Encrypt=False`
10. «اختبار الاتصال» ← لازم «تم الاتصال بنجاح».
11. إعدادات الفلترة:
    - حقل التاريخ في الـ Views: `TrxDate`
    - حقل الفرع في الـ Views: `BranchCode`
    - جدول الفروع: Schema `dbo` ، الجدول `Branches` ، الكود `BranchCode` ، الاسم العربي `BranchAraName` ، الاسم الإنجليزي `BranchEngName`
12. حفظ.
13. «اختبار جدول الفروع» ← لازم يظهر عدد الفروع.
14. أول مصدر بيانات للتينانت: تُنشأ اللوحات الجاهزة وشاشاتها تلقائيًا (رسالة «تم إنشاء ... لوحة معلومات جاهزة»).

## د. التحقق

15. تحديث الصفحة (F5) ← القائمة ← «لوحات المعلومات» ← فتح كل لوحة.
16. كل الرسوم تظهر بدون رسالة خطأ.
17. «فلتر» ← سنة فيها حركات ← «تطبيق» ← الأرقام تتغير.
18. «تصدير PDF» ← كل رسم في صفحة.

## هـ. لوحة إضافية (عند الطلب)

19. الإعدادات ← **تعريف لوحات المعلومات** ← «إنشاء من قالب» ← القالب + مصدر البيانات ← «نسخ القالب».
    أو «إنشاء» يدويًا: الكود، الاسم عربي/إنجليزي، مصدر البيانات الافتراضي.
20. الفترة الافتراضية للفلتر (اختياري، مثل «هذه السنة»).
21. ألوان اللوحة.
22. مكان الشاشة في القائمة (تُنشأ الشاشة عند الحفظ).
23. الرسوم: «إضافة من قالب» أو «إضافة رسم بياني» ← سحب الصفوف للترتيب.
24. حفظ ← «فتح لوحة المعلومات» للتأكد.

## و. صلاحيات باقي المستخدمين

25. الإدارة ← «صلاحيات المستخدمين» (أو الأدوار) ← نظام «لوحات المعلومات» ← «وصول» على شاشات اللوحات المطلوبة فقط.
26. شاشات «الإعدادات» (مصادر البيانات، تعريف اللوحات) لمدير التينانت فقط.
27. حفظ الصلاحيات ← المستخدم يعمل خروج ودخول.

## ز. مشاكل شائعة

| الرسالة | الحل |
|---|---|
| تعذر الاتصال / أيقونة الرابط المقطوع | «مراجعة الاتصال» ← نص الاتصال، البورت، المستخدم. |
| الـ View ... غير موجود في مصدر البيانات | إعادة تشغيل سكريبت الـ Views (خطوة 1). |
| الفلتر غير مطبق على هذا الرسم | طبيعي في رسوم المقارنة (آخر 12 شهر) وأعمار الديون. غير ذلك: إعادة تشغيل السكريبت. |
| الرسم فاضي بعد الفلتر | الفترة المختارة بدون حركات عند العميل. |
| الفلتر لا يظهر في اللوحة | حقل التاريخ/الفرع غير محدد في مصدر البيانات (خطوة 11). |
| لا توجد فروع | مراجعة جدول الفروع ← حفظ ← «اختبار جدول الفروع». |
| الشاشة لا تظهر في القائمة | F5، ثم مراجعة صلاحية «وصول» للمستخدم. |
| ألوان الرسم لا تتغير مع ألوان اللوحة | تعديل الرسم ← السلسلة ← زر «تلقائي» بجانب اللون. |
